**KYC 风控是真实存在的。** Anthropic 会不定期对账号触发身份验证，要求账号本人用政府颁发的实体证件完成验证，任何第三方都代办不了。要澄清一点：触发 KYC 和你用哪种方式充值没有直接关系，这是官方针对账号独立发起的风控。已有反馈里，Pro 会员触发的情况很少，更多集中在 Max 用户；触发概率可能与账号注册时间短、或使用批量注册的账号有关——这是基于案例的推测，不是官方结论。需要留意的是：充值成功后如果触发 KYC、又没完成验证导致账号用不了，这笔钱通常追不回来，也不算“充值失败”。下单前按这个最坏情况掂量一下。

**别把账号密码交给任何人。** 无论哪种方式，正规流程都只需要你的用户 ID 或激活码。需要你交密码、替你登录账号的，风险完全不在一个量级，直接避开。
